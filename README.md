# ArenaEngine

Легковесный движок для создания мини-игр (Spleef, TNT Run) с изолированными сессиями и управлением состоянием.

## 🎮 Возможности
- **Создание арен**: `/arena create <имя>`.
- **Установка спавна**: `/arena setspawn <имя>`.
- **Вход и старт**: `/arena join <имя>`, `/arena start <имя>` (минимум 2 игрока).
- **Таймер игры**: Автоматический отсчет 60 секунд с уведомлением в чат.
- **Остановка и очистка**: `/arena stop <имя>` возвращает игроков на спавн и очищает инвентарь.
- **Изоляция сессий**: Игроки разных арен не пересекаются.

## ⚙️ Установка
1. Скачайте `ArenaEngine.jar`.
2. Поместите в `plugins`.
3. Перезапустите сервер.
4. Создайте арену, установите спавн и запустите игру.

## 🧠 Технологии
- Java 25
- Paper API 1.21+
- Архитектура с менеджерами сессий (`Arena`, `GameSession`).
